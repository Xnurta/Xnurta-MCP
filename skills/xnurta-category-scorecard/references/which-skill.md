# Which skill?

| The question | Skill |
|---|---|
| How do my categories compare with the market and peers? Where should the budget go? What ROAS / ACOS goal is fair? | **xnurta-category-scorecard** (this skill) |
| One category: which searches to bid up or down, new keywords, price / pack; SQP audit; why share or sales dropped | xnurta-sqp-insight (plan mode for one category) |
| One SQP or peer number, or reading peer rows for a target | xnurta-query-market-data |
| Week-over-week or month-over-month recap, why a number moved | xnurta-weekly-ads-report / xnurta-monthly-ads-report |
| One named ASIN | xnurta-asin-deep-dive |
| Spend and efficiency by ad type, site, portfolio, weekday | xnurta-ads-structure-analysis |
| Product tiers and lifecycle (star / core / long tail) | xnurta-product-diagnosis |
| Search-term negatives and harvesting | xnurta-search-term-diagnosis |
| Budgets and bids for a promotion, before or during it | xnurta-promo-prep / xnurta-promo-monitor |
| Writing the confirmed daily budgets | xnurta-edit-ads (`campaign` + `updateBudget`) |
| Budget or target of an AI managed group | xnurta-edit-ai-group |

This skill changes only campaign daily budgets (through xnurta-edit-ads). Search-level bids and targets belong to
xnurta-sqp-insight. Do not add the sales estimates of the two together: a budget raise and a bid raise on the same
campaign buy partly the same clicks.
